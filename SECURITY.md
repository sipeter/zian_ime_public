# Security and privacy reports

Please report suspected security or privacy problems privately to **sdrxdev@gmail.com**.

Include the affected version, device/Android version and a minimal reproduction using non-sensitive sample data. Do not send signing keys, credentials, private recordings or complete user databases. Do not disclose an exploitable issue or personal data in a public Issue.

安全或隐私问题请私下联系上述邮箱，不要在公开 Issue 中披露漏洞细节或个人数据。
