# ZianIME 语音输入法

[English](README.en.md) · [使用说明](docs/USAGE.md) · [隐私政策](https://sipeter.github.io/zian_ime_public/privacy.html) · [问题反馈](https://github.com/sipeter/zian_ime_public/issues)

ZianIME 语音输入法是一款 Android 输入法，结合本地语音识别与中英文键盘，让你用说话或打字的方式输入文字。语音模型下载完成后，即可在手机上离线进行语音识别。

## 主要功能

- 在 Android 手机本地进行语音识别，支持实时文字预览。
- 中文拼音、英文、数字和符号键盘。
- 可选的本地识别文字日志：查看、搜索、删除与导出，默认关闭。
- 简体中文、繁体中文、英语、日语、韩语界面；界面语言与识别语言分别设置。
- 无需注册账号。

## 开始使用

支持 **Android 8.0 及以上的 64 位 ARM 设备**。语音识别速度受设备性能影响。

1. 安装后，在 Android 系统设置中启用 ZianIME 语音输入法，并切换为当前输入法。
2. 在应用设置中下载语音识别模型，建议使用 Wi-Fi。
3. 使用语音输入时授予麦克风权限。

详细步骤及常见问题见 [使用说明](docs/USAGE.md)。
